# Requirements

This file details requirements to support [github issue #1](https://github.com/kevinlee2198/playground-web-client/issues/1)
This feature requires this web client to allow a logged-in user to send friend requests to other users. Users should be able to accept or reject requests. Users should also be able to unfriend someone once they are friends with them. A user can block another user at any time.

People can also see the other users that you are friends with.

This feature is very similar to Facebook's friend system.
